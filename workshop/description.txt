[h1]东尼算法 - 遗物 / Anthony Algorithm - Relics[/h1]

[b]测试中[/b] -- 内容与数值可能随版本调整.
[i]WORK IN PROGRESS - content and numbers may change between versions.[/i]

每局用本局种子确定性地生成 60 件遗物,替换本局全部遗物掉落.核心机制与原版东尼算法一致:[b]触发与效果是独立片段,生成时随机重组[/b],因此会出现原版从未有过的组合.
[i]Each run deterministically generates 60 relics from the run seed and replaces every relic drop. Triggers and effects are independent fragments recombined at generation time, so combinations the base game never had can appear.[/i]

[h2]词条池 / Fragment pools[/h2]

触发条件与效果分开采样再重组;每个词条自带数值与目标,可直接读作一句遗物文本.同一局内片段不重复使用,故每局只抽到池的一个子集.
[i]Triggers and effects are sampled separately, then recombined. Fragments are not reused within a run, so each run draws only a subset of the pool.[/i]

[h2]负面与限制词条 / Downside and restriction fragments[/h2]

负面词条取自游戏中所有遗物的负面效果(含先古遗物):失去生命 / 生命上限 / 金币,获得诅咒,手牌虚无等.先古遗物的限制类负面也入池(不能获得金币 / 药水栏位,出牌数受限等).限制类与增益配对出现,不会是纯亏损.
[i]Downsides come from every relic in the game, Ancient ones included: losing HP / max HP / gold, curses, hand-Ethereal. Ancient restriction affixes also enter the pool (no gold, no potion slots, capped card plays). A restriction is paired with a benefit so it is never pure cost.[/i]

[h2]数据忠实度 / Data fidelity[/h2]

原子数据由本模组工具从游戏自身的遗物实现中提取,再经人工审计账本过滤.
[i]Atoms are extracted from the game's own relic implementations and gated by a hand-audited ledger.[/i]

[h2]遗物替换范围 / Relic replacement[/h2]

替换本局所有遗物掉落(含先古 / 商店 / 事件).若要保留原版遗物池,请勿订阅.
[i]Replaces all relic drops (Ancient, shop, events). Do not subscribe if you want the vanilla relic pool.[/i]

[h2]游戏内设置 / In-game settings[/h2]

[list]
[*][b]额外词条池[/b](默认关):遗物还可能获得从 [b]怪异炼化 - 遗物[/b] 搬来的卡牌级效果 -- 手牌获得保留 / 奇巧 / 虚无,或附上锋利 / 灵巧 / 注能
[*][b]四个生成权重[/b](触发 / 被动 / 增益 / 额外,默认均 100):决定各档的[b]抽取比例[/b],只有相互比例有意义;设为 0 即关闭该档.100/100/100/100 名义为 80/15/5;因被动与增益档片段少(8 与 5 个,每局每片段最多一次)且耗尽后落档,[b]实测[/b]约 89/6/5
[*][b]关闭所有负面效果[/b](默认关):遗物不再带任何负面 -- 不失去生命 / 生命上限 / 金币,不获诅咒,手牌不虚无,也无先古限制类词条.注意:[b]回合结束不自动弃手牌[/b] 不算负面
[*][b]金币与药水栏位仅在拾起时[/b](固定,无开关):这类效果只挂在“拾起时”触发上 -- 它们是永久货币,挂重复触发会复利式膨胀
[*][b]避免无效效果[/b](默认[b]开[/b]):遗物不会再抽到“在其触发时机无法生效”的效果(如“战斗结束时获得格挡”).另有[b]两类恒不生成[/b]:战斗结束时对敌方的效果,以及非战斗状态下需要战斗的效果
[/list]
[i]Extra pool (off): adds card-level effects ported from Qurious Crafting. Four weights set each band's ROLL (ratio only); 0 disables a band. 100/100/100/100 rolls 80/15/5 nominally and ~89/6/5 measured, because the small passive/benefit pools exhaust. “Disable all negative effects” (off) removes every downside. Gold and potion slots are granted on pickup only - they are permanent currency. “Prevent ineffective effects” (ON) drops effects that cannot work where they fire.[/i]

[h2]多人联机 / Multiplayer[/h2]

遗物定义是 (种子 + 生成设置) 的纯函数:同种子 + 同设置则两端生成同一批遗物.上述开关与权重都[b]参与生成[/b],联机两端必须取值相同.
[i]Definitions are a pure function of (seed + settings), so both ends regenerate identical relics. The toggles and weights are generation inputs: every player must use the same values.[/i]

[h2]与 怪异炼化 - 遗物 共存 / Coexistence[/h2]

可与 [b]怪异炼化 - 遗物[/b] 同时安装,两者的遗物池互不干扰.
[i]Can be installed alongside Qurious Crafting - Relics; the pools do not interfere.[/i]
