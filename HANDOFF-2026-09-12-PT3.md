### 3.3 Two real extractor defects (fixed, worth remembering)

1. **Value fell back to the class's first DynamicVar** -> `BigMushroom modify_hand_draw amt=20`, but 20 belongs to its `MaxHpVar`; the draw modifier actually uses `CardsVar(2)`. Fixed to **match the declaration by the var name referenced in the method body**. A wrong number is worse than no number.

### 3.5 The mechanism contract still in force

1. The data layer splits "condition/trigger" and "effect" into two independent fragment kinds.

## 5. Pitfalls and lessons

### 5.1 Most important lessons from this session

- **The keywords in a mod's name are a hard constraint.** Named "Relics" means the output must be relics. **Before reusing upstream data, ask: can this data source produce what the name promises?**
- **Reusable mechanism != reusable data.** The original AutoAnthony's condition-recombination mechanism ports to relics; its card-atom data does not.
- In extractors/generators, **refuse rather than emit a wrong result**. A wrong atom silently poisons the whole pool.

### 5.2 Environment traps

- Bash **cannot** `export` names with parentheses -> always use `dotnet-env.py`.
- **Never write to `C:`** - caches, builds, temp all go to `G:`.
- A subagent previously failed with **HTTP 429 rate limiting**; the main session must be able to take over directly (that is what happened with HeartShake).
- **Godot static members outside the engine are a native access violation** (`0xC0000005`) that **`try/catch` cannot catch**. Therefore: the data layer uses **embedded resources**, not `res://`; and the interpreter is split into a **pure planning layer + an engine execution layer**, with the pure layer touching no Godot statics (this is the hard architectural constraint of stage C, see `InterpreterTypes.cs`).
- BaseLib setting-label keys are `{ModPrefix}{StringHelper.Slugify(propertyName)}.title`. `Slugify` inserts underscores into camelCase: `EnableHeartShake` -> `ENABLE_HEART_SHAKE`. A mismatched key silently falls back to showing the raw property name and skips the hover tip (this defect was fixed in HeartShake).
- Before committing, confirm `.gitignore` covers `tools/**/bin/` and `tools/**/obj/` (45 files including `sts2.dll` once got committed; fixed with `reset --soft` + `gc --prune=now`).

### 5.3 Known noise (do not report again)

- `Asset not cached: res://images/packed/card_template/card_frame_sdf.exr`
- `Volume can't be set to NaN.`
- RID/shader leak warnings on exit
- `[Perfect] Harmony patch failed (AFTP absent?)`
- Treasure room `Proceed button not enabled after picking relics` (belongs to `RelicRewardChoices`)
